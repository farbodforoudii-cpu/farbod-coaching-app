# فربد کوچینگ — نسخهٔ نصب‌شدنی

نسخهٔ نصب‌شدنی (PWA) برنامهٔ تمرینی فربد کوچینگ: همان اپ کامل، روی گوشی، بدون اینترنت هم کار می‌کند.
اطلاعات هر مراجع روی گوشی خودش است و یک نسخه از آن در فضای ابری خصوصی فربد کوچینگ نگه داشته می‌شود،
تا با شمارهٔ موبایل و رمز روی هر گوشی دیگری برگردد. فقط فربد (مربی) آن را می‌بیند.

این مخزن فقط فایل‌های ساخته‌شده است؛ کد اصلی در مخزن خصوصی پروژه است.
